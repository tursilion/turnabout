This is an attempt to code a game out of the old Phoenix Wright - Turnabout Storm MLP cross-over fan video.

The game plays online using a TI-99/4A with TIPI or compatible for the web access. It also supports F18A for 
better graphics. There is also an HTML5 web based version. Today, the HTML5 version is seeing more updates
due to lack of interest on the TI side, but the engine may be of interest to some.

The images, sound effects and music are significant in size, so at the moment they aren't included here. To save github the large binary, you can grab a pack here: <a href="https://harmlesslion.com/zips/pw_data.zip">https://harmlesslion.com/zips/pw_data.zip</a>

I might forget to update this archive - if it's out of date, just drop me an email at harmlesslion and I'll update it for you.

The TI version is built into my Classic99 emulator: <a href="https://harmlesslion.com/software/classic99">https://harmlesslion.com/software/classic99</a>

The HTML5 version can be played here: <a href="https://harmlesslion.com/phoenix">https://harmlesslion.com/phoenix</a>
